# 下界合金转换机与下界精华

新增机器转换途径并保留现有配方。转换机工作在传送带/置物台上方两格，不制作运动动画；固定占用2048SU，每个物品100个有动力的连续游戏tick，转速不加速，断电/过载重新计时。一次转一个，堆叠输入逐个处理。

用户已确认：1烈焰粉、1地狱疣、1000mB岩浆→1000mB下界精华，仅下界合金搅拌机在工作盆中制作；每次转换消耗250mB。无额外加热要求。转换机内置4000mB精华专用流体槽，支持管道和桶；仅完成时扣精华与板材次数。

维护者选择：沿用Create BeltProcessingBehaviour及标准ProcessingRecipe序列化器，转换与专属搅拌采用独立RecipeType，避免普通搅拌机误做。板槽限一张下界合金板，右键插入，潜行空手右键取出；首次使用后在板的custom_data保存剩余15次，消耗最后一次时板消失。自动化物品能力同样限定板材。部分用过的板取出、保存、掉落后仍保留次数，不额外创建燃料物品或隐藏免费额度。

转换范围为现有14种方块机器（含红石链接器→无线终端），燃烧室另含空壳转换，共15条新转换配方；不包含手持工具、管理器、材料和无原版对应物的新转换机本身。结果一对一，保留输入组件及兼容方块实体数据，结果指定组件优先；空燃烧室结果BlazeCount=0，普通燃烧室=1。现有合成配方保留。

合成3×3：下界合金锭/下界之星/下界合金锭；龙息/附魔台/龙息；黑曜石/钻石块/哭泣的黑曜石。模型为静态机身及顶面显示的板材，无活动压头。沿用原生Shift概要、护目镜显示库存/次数/精华/进度。机器及物品防爆，物品防火。
