# 下界合金加工机械手实施计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 新增Create机械手（Deployer）的下界合金升级，一次动作批量处理同组物品。

**Architecture:** 继承原生DeployerBlock/BE，使用限定批量入口聚合逐件原生加工结果，一次提交传送带/置物台，逐件支付材料、耐久和容器返还。保留原生动作速度、应力、配方匹配、序列组装和世界交互。

**Tech Stack:** Minecraft1.21.1 / NeoForge21.1.219 / Create6.0.10-280 / Java21。

**Spec:** 用户要求“制作下界合金机械手，一次可以批量加工物品（和冲压机，搅拌机一样）”。对应Create官方机械手deployer，不改变原有搬运逻辑；已有mechanical_arm中文按官方更正为“下界合金动力臂”，ID及存档保留。

## 约束与决定

- ID `netherite_deployer`，版本0.3.10；板+原版deployer无序升级，防火、防爆、创造栏和中英文原生Shift概要。
- 批量只处理本次输入堆叠，每件应用当前同一配方一次，不将新产物再次递归加工；序列组装每件只推进当前一步。
- 按每件输入重新验证同配方；原生消耗材料、工具耐久、保留工具规则、随机产物及容器返回逐件执行。材料耗尽、工具损坏、配方改变即停止，保留未加工输入。
- 原生动作/RPM/应力倍率为1；不增加世界放置、攻击和挖掘的动作次数。原版deployer不受影响；移动结构保留原生单次世界交互。
- 保留原生筛选、红石、朝向、FakePlayer库存、能力及存档；修正原生按注册ID判定的移动向量识别。
- 贴图交指定美术对话，只新增必要机身PNG；动态轴/手掌沿用原版，不改旧图。不启动客户端、不使用RTX5060。
