# 独立 GUI 贴图接入计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 将过滤表、鼓风机和无限管理器的界面底图独立打包，支持资源包替换。

**Architecture:** 三个现有 Screen 直接读取各自 PNG；鼓风机按钮另用四列、三行状态图集。文字、物品、槽位交互与管理器原生控件保留。

**Tech Stack:** Minecraft 1.21.1, NeoForge 21.1.219, Create 6.0.10-280, Java 21。

**Spec:** 用户同意将现有代码绘制的背景、边框、槽位改为贴图。精确资源契约如下；外观由既有美术对话制作。

## 约束与决定

- 直接使用原生 `GuiGraphics.blit`，显式传入真实纹理尺寸；无需新框架或菜单变更。
- `textures/gui/netherite_filter.png`：288×236，保留四组 3×3 样本和玩家背包位置。
- `textures/gui/netherite_fan.png`：288×224，保留过滤器槽、玩家背包和模式按钮位置。
- `textures/gui/netherite_wireless_manager.png`：316×236；原生按钮、输入框与动态条目继续绘制于底图上。
- `textures/gui/netherite_fan_buttons.png`：248×114；四列依次水洗、熔炼、缠魂、烟熏，三行依次普通、悬停/聚焦、选中，每格 62×38。选中态优先。
- 动态文字、图标、物品不烘焙进 PNG；槽位位置由现有菜单决定，底图与之对齐。
- 美术对话只新增四张 PNG；本任务统一更新至 0.3.5 并提交推送，保留全部既有 PNG。
- 不启动图形客户端，不使用 RTX 5060。该低风险显示修改使用编译和资源核对，不新增镜像实现的单元测试。

## 检查重点

- PNG 超过 256 像素的边长必须使用真实宽高归一化，避免裁切或缩放。
- 图集全部 12 个区域均不越界，悬停与键盘聚焦共用状态，选中态保持可辨。
- 背景槽位覆盖现有菜单全部样本、背包、快捷栏位置。
- 文字、物品及原生控件覆盖于底图之上，保留所有菜单和输入处理。
- 发布包包含四张纹理，元数据为 0.3.5，旧美术不变；客户端视觉效果尚未实测。
