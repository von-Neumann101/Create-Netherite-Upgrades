# 转换机下界合金值与基础下界合金扳手实施计划

**目标：** 板材投入转换机即转为点数（新板16、旧部分使用板按剩余数），普通升级每件1点；新增基础下界合金扳手，主手方块触及+2，原版扳手行为保留。基础扳手可用原版扳手+板无序合成，或原版扳手经转换机1点升级。基础扳手再经转换机16点升级为既有模块化下界合金下界合金扳手。版本0.3.20。

**沿用规则：** 每件250mB下界精华、固定2048SU、100tick且断电重计时。原版下界合金升级模板仍可投入，转为1点。新工具防火防爆，无耐久；主手以外不授予新增触及，实体攻击距离不变。只维护NeoForge1.21.1；自动commit/push；不运行客户端或RTX5060。贴图仅委托指定美术对话。

**直接方案：** 保留转换机现有单槽物品能力作为投入端，插入时立即兑换并返回未接受部分，模拟不得改点数；不再保留可取出的实物板。使用非负int点数存档、同步和护目镜显示；满容量拒绝整件投入而非溢出。旧Plate库存迁移一次，不得重载双计。拆除/扳手拾取的转换机物品带NetheriteValue自定义数据，放置恢复；不另行退板。旧流体拆除规则保持。

配方沿用Create标准ProcessingRecipe参数，附加可选正整数`netherite_cost`默认1，双倍下界合金扳手配方为16；JSON和网络均保存此值。消费仅在输出有效且完整100tick后执行。物品转换继续保留输入组件，结果默认组件须正确叠加（进阶扳手需获得原有剑属性/无损耐久等）。

**分工：** 根负责转换机/配方序列化/旧测试迁移/注册/资源/语言/版本文档及唯一构建。独立工具任务仅负责新NetheriteWrenchItem、必要原生识别兼容Mixin、新工具GameTest、基础扳手物品模型和无序/转换JSON；不改共享注册或语言。原生WrenchItem含专用渲染，新增图标须避免被原生黄铜局部模型覆盖；所有原生WRENCH身份判断需要核对以保留常规扳手功能。旧模块化扳手持续能力不改。
