# 下界合金智能溜槽实施计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 保留智能溜槽原生过滤与红石暂停，增加无需风机的按物品上下行输送。

**Architecture:** 继承原生智能溜槽及其过滤行为。限定到新 BE 的 tick 接入点在原生行为 tick 后替换输送部分；上下行各一个真实堆叠缓存，通过原生物品能力与相邻容器/溜槽交换。界面配置两个样本及未匹配时的默认方向。

**Tech Stack:** Minecraft 1.21.1, NeoForge 21.1.219, Create 6.0.10-280, Java 21。

**Spec:** 用户要求可过滤并指定物品上下行，并明确选择无需鼓风机。以下界面与实现细节由维护者在现有项目约定内确定。

## 约束与决定

- 原生机身过滤控制允许进入的物品，保留列表、属性、数量和红石暂停语义。
- 空手右键打开设置；两个样本槽可复制普通物品或原版过滤表配置，按1/2分配上/下行，右键清除，不消耗样本。
- 上行匹配优先于下行；均未匹配使用可选默认方向，初始为下行。无须新增专用过滤器物品。
- 每方向一个最大原生堆叠，5 tick 后向相邻方块输出；两方向独立，避免相向物品占住同一缓存。规则修改用于新进入的物品，已缓存物品完成原方向。
- 相邻容器按目标方向选取可接收物品；同类溜槽之间主动推送，避免从输出侧重新抽回物品。原版溜槽继续使用其原生气流方向。
- 堵塞保留物品，保存重载保留缓存、规则和默认方向。拆除只掉落真实缓存，不掉落复制样本；Shift空手右键取出真实缓存。
- 新物品防火、防爆，原生Shift概要；原版智能溜槽+下界合金板无序升级。
- 美术交既有指定对话，只接入新PNG。版本0.3.6，更新双语README、技术文档与jar路径。
- 不启动客户端，不使用RTX5060；采用无图形GameTest实际验证。

## 检查重点

- 两个相邻新溜槽相向传送不同物品，无相互堵塞、抽回、复制或丢失。
- 原版过滤黑名单/属性/组件与精确抽取数量按原生匹配器执行。
- 满容器、固体出口及红石暂停保留两条缓存，模拟插入不改变真实物品。
- 持久化和拆除保留真实计数，样本永不变成掉落物。
- 原版溜槽、原生过滤交互与方块形状不受新类型接入影响。
