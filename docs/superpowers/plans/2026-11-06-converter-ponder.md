# 下界合金转换机用法思索实施计划

**目标：** 为转换机增加原生W思索入口，三段动画仅讲下界合金值获取、普通机器转换和两级扳手制作；不修改机器规则、配方或贴图。版本0.3.21，NeoForge1.21.1/Create6.0.10/Ponder1.0.82。

**场景：** 新 `client/ponder/NetheriteConverterScenes.java` 三个方法 `value` / `convert` / `wrenches`，场景ID `netherite_converter_value` / `netherite_converter_convert` / `netherite_converter_wrenches`，全部注册给转换机，共用新 `assets/createnetherite/ponder/converter/tutorial.nbt`。7×4×7舞台，转换机(3,3,3)，正下两格置物台(3,1,3)，西侧X轴轴杆(1..2,3,3)，最西轴杆下安山机壳支撑，右侧工作台(5,1,2)。字幕不堆叠，每段独立给足操作停顿。

- 获取值：板材右键投入→16点；空手右键/护目镜查看；原版升级模板→1点；已兑换耗材不再取回。
- 转换机器：正确放置，侧轴供能≥2048SU，用精华桶或管道补充流体，将原版冲压机放在下方；持续100tick后得到升级版，消耗1点和250mB精华，空手取走。
- 两级扳手：工作台无序合成原版扳手+板→基础扳手；或转换机原版扳手→基础扳手（1点/250mB）；再投入基础扳手→模块化扳手（16点/250mB），每次持续供能5秒。不给扳手另加入口，不展开模块能力。

Ponder为客户端虚拟世界，不会运行服务器加工逻辑；沿用原生storyboard编排投入、等待和产出，明示变更点数及流体状态，不把编排当作实际加工测试。转换机从纯Shift概要注册移除，保留原翻译兼容，入口遵循现有三种Ponder物品。其余场景/结构/字幕和76张PNG保持。
