# 下界合金弹射置物台实施计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 增加射程为原版两倍、蓄力进度八倍、平放但可自由选择斜向与高低目标的弹射置物台。

**Architecture:** 继承原版弹射BE，替换其EntityLauncher为三维目标版本；保留原生库存、红石、轨迹碰撞与飞行物持久化。用物品组件保存Shift右键选定的目标，服务端在真实放置/重新设定时验证并应用，客户端用同一轨迹类预览。

**Tech Stack:** Minecraft1.21.1 / NeoForge21.1.219 / Create6.0.10-280 / Java21。

**Spec:** 用户要求距离2倍、蓄力时间1/8、任意方向，并明确选择保持平放、目标自由选择，不新增贴墙倒挂。

## 约束与决定

- ID为 `netherite_weighted_ejector`。水平直线半径、垂直高度差限制分别为Create最大距离配置的2倍（默认64）；斜向按水平欧氏距离，不按方形范围扩大。
- 原生蓄力进度乘8，同距离同RPM的蓄力阶段缩短至约1/8，仍受整tick和原版弹射动作时间影响。无动力不蓄力，应力与网络RPM沿用原版。
- 手持新置物台Shift右键选目标，再正常放置；同样手持带目标的物品右键已有新置物台可重新设定，不消耗该物品。原生库存、数量与红石操作继续保留。
- 目标保存完整三维相对偏移；服务器限制范围、维度和编辑条件，拒绝不能表达三维目标的旧原版两整数设置接口。飞行中不允许改向；空闲修改时清除旧碰撞记录并重新扫描。
- 沿用原生实体运动动力学与虚拟物品碰撞扫描，水平运动按完整目标向量旋转，物品轨迹终点校正至真实目标；仍被实体方块阻挡，不穿墙。
- 新物品防火防爆，板+原版弹射置物台无序升级，原生Shift概要。静态、物品、普通渲染与Flywheel上盖都使用新增材质；木头和轴保留原版。
- 目标/飞行队列保存重载，拆除飞行物不丢不复制。原版弹射置物台不受影响。
- 贴图交指定美术对话，只接入三张新PNG；版本0.3.8，同步README/技术文档/产物路径。禁用RTX5060，不启动客户端。

## 检查重点

- 斜向实际传送物品、不同高度与纯竖直方向有限数值，不仅修改预览。
- 2倍边界与斜向圆形边界、存档重载不被原版32格截断；非法目标保持原设定。
- 蓄力倍率、无动力停机、红石暂停、原版弹射机不变。
- 飞行中存档、障碍物和拆除保持真实物品计数。
- 最后一件物品放置也正确应用目标，客户端预览与服务器使用同一目标/轨迹计算。
