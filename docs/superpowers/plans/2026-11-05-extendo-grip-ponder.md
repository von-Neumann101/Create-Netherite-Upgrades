# 下界合金伸缩机械手思索实施计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 为下界合金伸缩机械手添加两段原生W思索，介绍副手取液和主手临时供能。

**Architecture:** 沿用现有PonderPlugin/CreateSceneBuilder与双语共享字幕，新增5×4×5结构，两个原版储罐夹着强力机械泵，泵北侧布置与泵啮合、保持静止的X轴小齿轮。取液场景编排真实储罐的1000mB减少和水桶结果；供能场景仅将点击泵设为16RPM，让原生虚拟流体逻辑搬运水，松开后归零。核心物品、Mixin、贴图及其他思索保持不变。

**Tech Stack:** Minecraft1.21.1 / NeoForge21.1.219 / Create6.0.10-280 / Ponder1.0.82 / Java21。

**Spec:** 用户要求“给下界合金伸缩机械手也制作思索动画，介绍副手辅助装液体和主手给工作方块供能的用法”。沿用既定风格：原生W、只讲用法、中英文、禁用RTX5060，不启动客户端。无须新GUI或贴图；取液限定主手空桶、副手机械手，主手供能说明持续瞄准长按、仅驱动点击方块、松开停止与背罐空气优先/耐久兜底。不扩展机器能力或传动网络。
