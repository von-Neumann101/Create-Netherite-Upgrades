# 下界合金伸缩机械手实施计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 新增触及距离比原版再多3格、可辅助生存玩家用桶取储罐流体、可手动供能的下界合金伸缩机械手。

**Architecture:** 继承Create伸缩机械手及原生背罐空气/耐久消耗，通过限定Mixin让原生距离、消耗与伸缩动画识别新物品；额外距离按每只新机械手+3。储罐只在主手空桶、副手新工具时开放生存取液。长按右键手动驱动当前工作方块，采用不写入存档的临时供能状态，松开即停。

**Tech Stack:** Minecraft1.21.1 / NeoForge21.1.219 / Create6.0.10-280 / Java21。

**Spec:** 用户要求“更长的触及距离（多3格）”“副手时生存玩家能直接用桶从流体储罐装液体”“主手可直接给工作方块传递恰好够强力机械泵工作的应力，需要消耗耐久或压缩空气”。用户已确认“只驱动点击的工作方块”，不通过连接轴网络继续供能。

## 约束与决定

- ID `netherite_extendo_grip`，版本0.3.9。板+原版伸缩机械手无序升级，防火、防爆、创造栏及中英文原生Shift概要完整。
- 单只加成为原生3+新增3=6格；双持原生5格基础上，每只新工具再加3，混合双持为8、两只新工具为11。只增加方块触及，实体远距交互继续沿用Create原逻辑。
- 耐久上限沿用原生200。破坏、放置、攻击继续原生消耗；成功取一桶消耗一次，持续供能起始及每20tick消耗一次。优先使用背罐，空气不足时扣1耐久；创造及原生禁用消耗配置沿用原生。
- 正常与下界合金储罐均支持，保留流体能力/组件及真实1000mB计数。普通桶无新工具时维持原版行为，不开放存入流体或其他容器的新行为；取液失败不扣工具资源。
- 手动供能采用16RPM，基础容量跟随强力泵应力配置（默认16SU/RPM，即256SU）。工作方块自身需求超过容量时不能启动，不覆盖已有动力和发电机；长按时逐tick验证距离、视线、权限和所持工具，松开、移开、切换、断线或区块/存档重载不保留免费动力。
- 贴图由指定美术对话新增，静态与动态伸缩分件接入同一新UV图，原有PNG不变。禁止RTX5060，不启动客户端。

## 文件职责

- `content/equipment/NetheriteExtendoGripItem.java`：继承、额外距离、资源消耗和长按交互。
- `content/equipment/HandheldKineticPower.java`：临时供能状态接口和生命周期，不创建新方块或永久动力源。
- `mixin/NetheriteExtendoGripMixin.java`：原生伸缩机械手识别和距离补充。
- `mixin/NetheriteGripTankMixin.java`：生存空桶取液入口。
- `mixin/HandheldKineticPowerMixin.java`：仅正在手动驱动的工作方块显示临时RPM。
- 客户端限定Mixin与分件模型：原生伸缩动画和新材质接入。
- `NetheriteExtendoGripGameTest`：真实玩家物品、储罐流量和泵行为，发布包排除测试。
