# 鼓风机四个原版过滤器槽实施计划

> **For agentic workers:** Use superpowers:executing-plans inline, followed by one fresh-context whole-change review.

**Goal:** 水洗、熔炼、缠魂、烟熏各有一个原版过滤器槽；未匹配物品继续使用手动所选模式。

**Architecture:** 鼓风机保存四个真实、上限一件的 Create 原生过滤器槽，按原有模式顺序调用原版匹配器。沿用四个模式按钮并在下方对齐各自插槽；旧安装物独立保管，打开菜单时退还，避免旧物品或规则丢失。

**Tech Stack:** Minecraft 1.21.1, NeoForge 21.1.219, Create 6.0.10-280, Java 21。

**Spec:** 用户明确要求四个槽只能放原版过滤表，鼓风机不再使用专用下界合金过滤器，未匹配仍按选择模式加工。

## 约束与决定

- 仅接受 Create 命名空间的 `FilterItem` 原生类型，支持普通过滤表、属性和包裹过滤器；普通物品、专用下界合金过滤器及其他模组类型均不可安装。
- 四槽为真实物品槽，每槽一件，可正常放取、Shift快捷转移。模式按钮仅设置未匹配物品的回退模式；四个槽始终固定对应各自加工方式。
- 匹配优先顺序沿用水洗、熔炼、缠魂、烟熏。通过原版 `FilterItemStack.of(copy).test(level,target)` 保留配置语义，空槽跳过。
- 旧 `Filter` 单槽原物保留为 `LegacyFilter`，不生成或复制原版过滤器；首次打开新菜单退还原物及完整规则，未打开即拆除则掉落原物。新 `Filters` 为四槽格式。
- 旧专用过滤器保留注册、数据和查看菜单以兼容存档，移出创造栏、删除合成配方及专属思索入口，改为原生 Shift 兼容说明。新鼓风机拒绝它。
- 思索只改用法和示例过滤器，不改变结构、支撑安山机壳或加工倍率。贴图仍由指定美术对话提供，仅调整鼓风机GUI过滤器行。
- 版本 0.3.7，同步双语README、技术文档和jar路径；不启动客户端或使用RTX5060。
