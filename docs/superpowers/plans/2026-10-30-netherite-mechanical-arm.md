# 下界合金机械手实现计划

**目标：** 新增 `createnetherite:netherite_mechanical_arm`，动作进度和上限为原版 3 倍，应力基础消耗为当前原版配置的 1.5 倍；用户追加要求扩大工作范围，采用原版距离的 3 倍，默认 5→15 格。

**架构：** 继承原生 ArmBlock / ArmBlockEntity / ArmItem，保留实际动能转速。通过限定新 BE 的 Mixin 修改移动速度上限表达式、初始化加载范围及目标距离校验；客户端适配原生选点与放置请求。复用原版搬运、模式、红石、燃烧室喂料、保存与渲染，专用分件模型由本任务接入；贴图交既有美术对话，不改旧素材。

**边界：** NeoForge 1.21.1 / 21.1.219 / Create 6.0.10-280 / Java 21；不维护 Forge 1.20.1。新方块抗爆，物品防火并继承命名空间防爆；合成用下界合金板 + 原版机械手。提交仅包括本任务文件，按用户约定自动 commit / push。

## 文件

- `content/kinetics/mechanicalArm/NetheriteArmBehavior.java`：速度、应力、距离和相对目标校验共用计算。
- `NetheriteMechanicalArmBlock.java` / `NetheriteMechanicalArmBlockEntity.java`：类型绑定和范围接口；物品复用 ArmItem。
- `mixin/NetheriteMechanicalArmMixin.java`：原生 BE 动作表达式、加载范围和目标反序列化前的范围检查。
- `mixin/NetheriteArmSelectionMixin.java`（客户端）：识别手持的新机械手；放置后保留扩大范围内选点。
- 客户端分件模型映射及 renderer / visual Mixin：复用原生动作并接入专用分件资源，兼容护目镜切换。
- 注册、创造栏、模型、配方、掉落、工具标签和语言；README / NeoForge 技术文档。
- `src/boilerTest/.../NetheriteArmTest.java` 与 `armRegressionTest`：速度上限、反转、动态应力、范围边界与相对目标 NBT。
