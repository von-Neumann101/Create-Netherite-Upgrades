# 下界合金动力锯实施计划

**规格：** 新增 `netherite_mechanical_saw`，一个原版加工周期处理整叠输入；原生切割、石切、序列组装、过滤、余料与输出规则保留。砍伐计算速度为原版2倍，应力沿用原版；固定锯和运动结构锯伤害均为原版1.8倍。物品防火、方块和掉落物防爆。用户已确认2倍砍伐及256RPM手持伤害基准。

**扳手：** 新增SAW选项，可作为九种可选模块之一装入既有八个真实槽位，仍只激活一个。长按右键持续锯击视线前方攻击范围内的最近目标，墙体阻挡；256RPM原版锯伤害10，乘1.8为18。沿用原生受伤无敌间隔，不绕过PVP/队伍规则，松开或切换模块即停。

**实现：** `NetheriteSawBlock/BlockEntity/MovementBehaviour`继承原生Saw实现。库存允许整叠，start调用单件的时间参数消除数量耗时倍率，原生逐件roll结果。覆写getBreakSpeed/getBlockBreakingSpeed为2倍；固定锯显式1.8倍伤害，运动锯在原生伤害调用处条件缩放，保留原版其他处理。使用原生SawRenderer/SawVisual和模型骨架，材质由指定美术对话提供。

必要兼容：实际大产物列表超出原生31输出格时按产物数量扩容，保持保存和自动输出；补原生锯刃面not-supportive装配判定及机械臂SawType投料判定。

**公共接口：** `NetheriteSawBlock.damage(float rpm):float`返回原生DrillBlock.getDamage(rpm)*1.8；`BoosterItems.NETHERITE_MECHANICAL_SAW`注册物品；`WrenchModule.SAW`映射新物品；`WrenchSaw.tick(Player,ItemStack)`处理持续伤害，`WrenchSaw.register(IEventBus)`优先处理实体右键并开始原生use。根代理实现机器/注册/资源，独立任务实现WrenchSaw、扳手Item接入及专用测试，避免共享文件冲突。
