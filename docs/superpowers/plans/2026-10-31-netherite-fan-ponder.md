# 下界合金鼓风机思索动画

**目标：** 为下界合金鼓风机提供两段用法思索，包含接入动力、内置四种加工模式、放入物品、过滤器规则与未匹配回退。鼓风机下方用安山机壳支撑；字幕提供中文和英文，过滤器物品共用规则教程。

**实现：** 使用锁定的 Ponder 1.0.82 `PonderPlugin` / `PonderSceneRegistrationHelper`，在客户端 setup 注册。两个 storyboard 复用本模组独立结构模板，以原生场景指令演示支撑方块、风机、置物台、加工物品、鼠标提示与关键帧；复用现有机器和贴图。演示按 Ponder 原生做法编排加工结果，不修改实际机器规则。

**文件：** `client/ponder/BoosterPonderPlugin.java`、`NetheriteFanScenes.java`；`assets/createnetherite/ponder/fan/tutorial.nbt`；客户端注册、中英文语言文件、README 与 NeoForge 技术文档。

## 验证重点

- 不借用原版物品 ID 注册，不覆盖原版思索；客户端专用注册。
- 红羊毛水洗成白羊毛、粗铁熔炼成铁锭、沙子缠魂成灵魂沙、生牛肉烟熏成牛排，均使用实际配方对应结果。
- 过滤器优先，未匹配物品使用当前模式；已装过滤器时仍可切换模式。
- 内容仅讲用法，不展示速度对比、倍率或配置。
- 不得使用 RTX 5060；本次修订不启动游戏客户端，使用无图形界面的构建和资源检查。
- 区分编译/结构/资源检查、思索播放检查与真实世界加工实测；不为动画添加只镜像实现的单元检查。

## 初版结果（修订前）

- 独立审查发现风口与置物台同高会被碰撞形状挡风；已统一抬高风机/轴，更新坐标引用、NBT 和展示选区。原生 AirCurrent 会搜索气流下一格的置物台 handler。
- 修正后完整离线构建与全部 172 项现有回归通过；103 个 JSON、18 条双语 sharedText、3 个双语标题，以及 jar 内结构、语言和场景类核对通过。
- 已在独立测试世界实际打开鼓风机三段英文思索并检查切换、示例物品、过滤规则/回退和速度对比，过滤器共用入口也已打开；没有场景加载或播放异常。
- 测试客户端原版资源未下载完整，语言列表为空，因此中文仅做资源校对，未记为中文界面播放已验证。Ponder 编排演示不等同于真实加工计时实测。

- 移除速度对比场景及其注册、双语标题和三条性能字幕，将物品放置说明并入模式教程。

- 将禁止使用 RTX 5060 的约束写入项目约定，本次不启动游戏客户端。
